EXACT PDF RECREATION
=====================
This version uses each original PDF page converted directly to SVG.
SVG is vector/code rather than a raster screenshot, so the layout, text, images,
colors and positioning remain faithful to the supplied PDF and scale responsively.

Open index.html in a browser.

Important:
- This version prioritizes visual fidelity, so it does NOT attempt to rearrange
  individual PDF elements into separate HTML blocks.
- The SVG contains the PDF's rendered text/graphics as vector elements and its
  embedded images. It can be edited with an SVG/vector editor if individual
  elements need modification.
